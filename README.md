## 🔨 Some projects I built

- **[readme-onclick-animation](https://github.com/qvd808/readme-onclick-animation)** — the reason the image up there can do that. GitHub strips `<script>` out of every README, so this smuggles the animation past it with an edge proxy and a 12-second grudge held in Redis.
- **[factor_rl](https://github.com/qvd808/factor_rl)** — an agent that learned to factor polynomials by trial and error instead of being handed the algorithm. You can [watch it think](https://qvd808.github.io/factor_rl/), one step at a time.
- **[dafny-verify-loop](https://github.com/qvd808/dafny-verify-loop)** — hand it a Dafny spec, it writes a body that actually verifies. Built for small models that can't invent an algorithm, a loop invariant and a termination proof all in the same breath.
- **[CAT](https://github.com/qvd808/CAT)** — Convoluted Agent Trying to code. Describe a system, it prototypes it. The name is the most accurate documentation in the repo.
- **[ascii-galaxy](https://github.com/qvd808/ascii-galaxy)** — an ASCII galaxy banner for your README. My most-starred project, which says something about all the others.
- **[risc-v-logism](https://github.com/qvd808/risc-v-logism)** — a RISC-V CPU drawn out gate by gate, ALU and register file and all, before letting it near real hardware.
